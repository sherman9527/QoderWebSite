解释主线：脑、手、脚分家了

两张表答不了的那一问才是重点：它在哪台机器上执行。官方稿里最被低估的一句是，Muse 跑在自己专属的一台云端计算机上。拆开是三件事——「想」由 Muse Spark 完成，可以留在远端集群；「做」发生在 Secure VM 里：开浏览器、填表单、跑脚本、存文件和凭证；这台机器不随用户退出 App 而停。脑与手脚就此分家，一人一台、彼此不可达。

后面九章只追问三件事

这台虚拟机跑在谁的机房里、一台要多少 vCPU 和内存、开一小时多少钱。模型能力是共享的天花板，机器台数才是这轮需求的分母。本章只立判据，不给投资结论。

为什么需要「一台电脑」，而不是一个函数

状态：第二步得读到第一步

函数调用是无状态的：传参、返回、结束。可「导报表发财务」要登录、翻文件、改格式，登录态和刚装好的依赖都得活到下一步。阿里云无影 AgentBay 把这层需求拆成浏览器、代码空间、云电脑、移动端四个预置环境，官方文档写明支持跨平台数据持久化和状态连续性；All-in-One 沙箱里一个 linux_latest 会话同时提供桌面、浏览器、代码三个入口，隔离走 VPC 网络加独立容器。

权限边界：独立内核值多少钱

两条老路都不便宜。容器共享宿主内核，腾讯官方对比表把 Docker 完整启动系统标为 200 毫秒，但内核层逃逸会波及同机所有租户；传统虚拟机给独立内核，代价是秒级启动和整套系统的内存。腾讯云 2026 年 4 月开源的 Cube Sandbox 走中间路线：基于 RustVMM 与 KVM 的 microVM，每箱一套独立内核，裸金属自测单并发创建 60 毫秒内、自身内存开销 5MB 以内，单机能跑数千实例；密钥由七层代理托管，箱内代码读不到。

几分钟上万个：microVM、快照、预热池怎么配合

先拆时间线

你点下运行，到 agent 跑出第一行结果，中间至少五段：镜像落到本机、内核带起虚拟机、内存与根文件系统就位、出口配通、调度器腾出机器。那个毫秒数通常只量一段。

五段时间线

  1. 镜像分发只传差量层，按需读取把整包下载换成用到哪读到哪；代价是首读仍要回源。 eStargz 引 FAST'16：拉取占容器启动 76%。Nydus 称阿里云镜像加载 20 秒降到 0.8 秒。
  2. 内核与引导只留极少模拟设备，不搬整套 PC 固件。代价：官方写明不做流量过滤。 官方：5 个模拟设备，1 vCPU/128 MiB 下开销 ≤5 MiB。
  3. 内存与根文件系统冷启动从头跑 init，快照把跑好的状态直接铺开，省得最多也最容易漏状态。 官方文档不给恢复延迟数字。
  4. 网络算力先好、出口后到是常态：TAP、路由、地址池都要提前备好。 CubeSandbox 预建 TAP 池默认 500 个，开 1000 个要先调大。
  5. 调度与预热留几个常驻，来单直接分配；不留就排队建机器。超卖把代价转到尾部延迟。 Knative 的 min-scale 与 scale-down-delay；AWS 称预置并发可达两位毫秒级。

快照漏在哪

Firecracker 对快照比多数厂商谨慎：恢复延迟一个数字都不给，只提醒 cgroups V1 上会明显变慢、内核启动早期打的快照会直接崩。更硬的是安全警告——同一个快照恢复两次，标识符、随机数种子、熵池和一次性 token 就都重复了，官方原话是视为不安全。

一个沙箱一个出口 IP：地址从哪来，怎样才算合规

判的是网络身份，不是账号身份

反爬判的不是“你是谁”，而是“你从哪张网络来”。Cloudflare 把它写成了字段：verified_bot 靠反向 DNS 确认源 IP 属于声称的服务，再比对 ASN 段与公开名单，没通过的落进 1–99 的 bot score。同一 ASN 下有滥用记录，整段信誉被拉平，机房段因此吃亏。多账号还要彼此隔离：同一出口 IP 上的 N 个账户会被当协同信号，共用出口容易被一起处置。

合规有三层，别混成一件事

技术合规查登记链。RPKI 让持有者签名声明“这段前缀由哪个 ASN 发起”，即 ROA，别的运营商据此把宣告判成 valid 或 invalid。登记、ROA、IRR 对得上，地址才算真的；AWS 还审查地址历史，声誉不良可拒收。

平台合规查条款。LinkedIn 用户协议（2025-11-03 生效）第 8.2 条禁了三件事：用脚本或爬虫抓取服务、“绕过或规避访问控制与使用限制”、用 bot 制造非真实互动。GitHub 条款（2026-04-27 生效）D.9 更狠：用自动化手段抓公开内容训练商用 AI 系统，即视为放弃自家条款对 GitHub 抓取的约束，学术研究和月活低于 7 亿者除外。

法律合规没有统一答案。美国 CFAA 的争点集中在“未经授权”。2026 年 3 月，加州北区一家联邦法院就 Perplexity 的 Comet 代理发布初步禁令，禁止它访问受密码保护的 Amazon 账户。绕开访问控制、批量注册、流量转售的边界各法域不一，本节只描述机制，不下合法性结论。

为什么 CPU 突然成了新需求：GPU 管脑，CPU 管手脚

三条机制：钱具体花在哪

CPU 这轮缺货是真的，但把账全算在 Muse 头上就夸大了。付钱的是云厂商的通用服务器采购，机制有三条。

一、执行负载偏 CPU 与 I/O。一次 agent 任务里，模型生成只占一小段时间，其余是开浏览器、编译、解压、加解密、文件与网络调用；已有系统方向的工作把工具调用直接列为 agent 链路的性能瓶颈。

二、配比在变。AMD 在 2026 年 5 月 5 日的一季度电话会上说得很直白：推理与 agentic AI 抬高了服务器 CPU 需求，因为要额外的 CPU 做编排、数据搬运和并行执行，CPU 还要当 GPU 的 head node；同场它把服务器 CPU 市场年增速预期从约 18% 上调到 35% 以上。

三、沙箱密度。Meta 官方称 Muse 跑在 Muse Secure VM：每个用户一台专属的云上机器，自带浏览器，同机还跑着 Sentinel 审批出口流量。一个用户换来的不是一次调用，是一台常开的电脑。

三件事别混。GPU 服务器出货仍在涨：TrendForce 2026 年 4 月 15 日预计 2026 年 AI 服务器出货同比增约 28%，含 AI 的整体服务器只增约 13%，而这个 13% 还是从接近 20% 下调来的。CPU 拿的是增速差，不是替代。AMD 数据中心收入由 EPYC 与 Instinct GPU 并列驱动，季度数字拆不出 CPU 贡献。买方也在控成本：2026 年上半年起，部分 CSP 与 OEM 把 RDIMM 从 96GB、128GB 退回 32GB、64GB。

怎么证伪：盯两个口子

你要证伪，盯两个口子。看结构：云厂商资本开支里通用服务器与加速器的比例，以及 CPU 缺货的措辞还在不在——TrendForce 2026 年 7 月 9 日记录到服务器 CPU 缺货已拖慢整机组装，PCB 与 CPU 的交付周期接近一年。看价格：常规 DRAM 合约价 1Q26 环比涨 93%–98%，服务器 DRAM 合约价 3Q26 只预计涨 13%–18%，因为多家美国 CSP 用多年期长约锁住了价。交期与长约外的成交价一起响，才是真缺货。

中游格局：四类玩家，卖的东西其实不一样

四家给的压根不是同一张发票

运营商卖点位数：一个账号一台桌面，按月起算，续约走集采。公有云卖小时：开机才计费，关机把 vCPU 收回池子。云手机卖整机：一台 ARM 服务器带 N 个安卓实例，按天卡月卡零售。终端与软件商卖的不是时长，是一台瘦客户机加一份许可，验收当天付清。

按时长跑的：公有云大厂、中立沙箱云

  • 按秒计量、整点出账，关机停计计算资源
  • 计算、存储、带宽三条拆开发票，逐项可谈
  • 沙箱单独立成产品线，SDK 与 MCP 供智能体调用；独享出口 IP 另成一档

不按长跑的：运营商云、终端与软件商

  • 运营商只有包月目录价，限时段另设档，无按需小时价
  • 智能体入口是“云电脑里预装助手”，不是外部程序可调的沙箱 API
  • 终端商硬件按台、平台按套、用户按授权，收入靠维保与扩容

单位经济：一台沙箱一小时多少钱，什么时候比自建划算

一次任务，而不是一个机柜

别按「一台机器多少钱」想，按「一次 agent 任务多少钱」想。天翼云电脑政企版 4核8GB 按需 0.52 元/台·小时，阿里云无影 4vCPU/8GiB 按需 0.727 元/台·小时，两家都只有运行状态计计算费、关机休眠停计；盘另算：阿里云 0.00035 元/GiB·小时，从创建到释放全程照收。

假设日均 2000 个任务、每任务 12 分钟、集中在 8 小时窗口（平均并发 50 台，峰值取两倍 100 台），一个月 12000 台·小时，计算费 6240 元（天翼云）到 8724 元（阿里云）。

最容易漏的三项：流量、IP、盘

流量：天翼云 0.36 元/GB，阿里云华北 2、华东 1 等 BGP 多线 0.80 元/GB，香港精品线路 3.0 元/GB。按每任务 100MB、月 6 万任务算，是 2160 元到 4800 元。

出口 IP：阿里云公网 IP 保有费 0.02 元/个·小时，100 个地址常驻持有是 1440 元/月；两家都写明 IP 直绑实例时免收——「一个沙箱一个出口 IP」走绑定还是地址池，是写进账单的决策。存储：用完即销毁近乎为零，保留 100 台 × 80GiB、0.25 元/GiB·月就是 2000 元。

自建什么时候反超

2025 年 1 月中央国家机关政采一份中标公告里，浪潮 NF5280G7（2U 双路，2 × 至强 6530 共 64 核、512GB 内存）单价 78000 元、买了 12 台。假设 3 年直线折旧、无残值，摊 2167 元/月；北京一家 IDC 公开报价单上 42U 整柜含 10M 独享带宽 50000 元/年，一柜放 20 台 2U，摊 208 元/台·月。合计 2375 元。

再把核切开：64 核 ÷ 4vCPU = 16 份（内存 512÷8 = 64 份，CPU 先到瓶颈），每份 148 元/月，按 720 小时满摊即 0.21 元/台·小时。自建 3 台 7125 元/月，对应天翼云按需 13700 台·小时——月运行量过了这个数（约每天 2300 个 12 分钟任务）自建才便宜，这还没算运维人力、备件和超额电力。

报价页不等于合同价

以上全是公开标价：政采单价是 12 台的批量成交价，IDC 报价单自己注明「促销价、每月限量前 20 名」，云厂商大客户折扣走合同、不上网。这些数只够比量级、找交叉点，真做预算得自己询价。

边界与风险：这轮需求里哪些是真的，哪些是叙事

延迟：改不掉的一条

ITU-T G.1010 给交互式网络服务的门限是单程时延 150 毫秒、丢包 1%。桌面串流要低于这条线，手上才没有黏感。150 毫秒当整条往返预算，跨太平洋上万公里的光路只算传播就花掉大半——可用半径天然是就近部署。更要命的是尾延迟：一次 300 毫秒抖动，人补点一下鼠标就过去，agent 判成卡死，整段任务重跑。

合规：当天就没有产出

Cloudflare 在 2025 年 8 月点名 Perplexity 用未声明的爬虫绕过站点禁令，并拦掉它自称「用户驱动」的流量。同一片防护下的站点，人和 agent 一起进不去。出口 IP 越像住宅宽带、共用网段越大，连带被封的面积越大。这一条不以罚款收场，是当天没有产出。

平台依赖，和经济性

模型厂商自带执行环境：OpenAI 2025 年 7 月的 ChatGPT agent 自带一台虚拟机，微软 2025 年 11 月的 Ignite 也把「给 agent 用的 Windows」列为主线。模型方开始送机器，中间层丢的是续约谈判里的定价权。成本要按重试算——一次成功背后是几次白烧的机器时和 token，所以完成率比单价更能决定这门生意。

证伪清单

① 只有合作表态、公告无金额无交付期。② 最近一季 10-Q 的 property and equipment 明细：加速器涨、通用服务器与网络持平，说明手脚没被买。③ 沙箱价目表按 vCPU·小时同口径比两季，不降反升就是没规模化。④ OSWorld 这类公开榜单半年不动。⑤ 目标站点服务条款写明禁止自动化访问。

哪条是真的

派生自「agent 需要一台机器」的 CPU、内存与出口 IP 需求是真的，已经写在价目表里。要时间证明的是量级：一个任务值多少机器时，以及人不再自己开电脑这个前提。资本开支的口径里大头仍是卡与电，路透 2026 年 7 月已在写有人为增速放缓布局。两件同时成立，外溢到沙箱的那部分更像存量重分配。
