# Spec Delta

## Purpose

定义黄金模板的渲染行为：模板真身只有一处，产物是离线自包含的静态页面，且同一骨架下每个领域呈现可辨识的独立视觉身份。

## ADDED Requirements

### Requirement: 模板真身唯一

黄金模板 SHALL 只有一个实现来源；预览工作台与最终静态产物 SHALL 由同一实现渲染，MUST NOT 存在需要人工同步的第二份排版定义。

#### Scenario: 改样式两处同变

- **WHEN** 修改模板的某项排版规则
- **THEN** 工作台预览与下一次生成的静态产物同步反映该修改
- **AND** 无需改动任何其他排版文件

#### Scenario: 禁止手改产物

- **WHEN** 有人绕过模板直接编辑产物 HTML 的样式段
- **THEN** 质量验收报告该产物与模板指纹不一致并判为 fail

### Requirement: 产物离线自包含

生成的 HTML SHALL 不依赖任何外部网络资源即可完整呈现：样式内联、图片走同目录相对路径、不引用 CDN 脚本、外链字体或远程样式。

#### Scenario: 断网双击可开

- **WHEN** 在无网络环境用浏览器直接打开产物 HTML 文件
- **THEN** 版式、文字与全部配图正常呈现，无占位破图

#### Scenario: 无外链资源

- **WHEN** 扫描产物 HTML 的资源引用
- **THEN** 不存在指向 `http(s)://` 的脚本、样式、`@import` 或样式内 `url()` 引用

### Requirement: 结构化区块渲染

模板 SHALL 按带类型的区块渲染内容，至少支持：正文、键值表、时间线、价格表、卡片组、步骤、引言、事实条、对照、提示。MUST NOT 把整节内容压成一坨无结构文本。

#### Scenario: 时间线按序呈现

- **WHEN** 某章节含时间线区块
- **THEN** 条目按时间顺序呈现且带年份标注

#### Scenario: 未知区块类型

- **WHEN** 数据中出现模板不支持的区块类型
- **THEN** 渲染失败并指明该区块位置，MUST NOT 静默丢弃内容

### Requirement: 每个领域视觉身份可辨识

系统 SHALL 保证不同领域的页面在配色与字形上可区分，MUST NOT 让多个领域共用同一套视觉 token。

#### Scenario: 相邻主题不雷同

- **WHEN** 比较任意两个已生成领域的主色板
- **THEN** 两者的主色与强调色差异超过验收阈值
- **AND** 差异不足时质量验收判为 fail

#### Scenario: 规避生成页通用套路

- **WHEN** 审查任一领域页面的视觉方案
- **THEN** 该页面不得整体落在"奶油底＋衬线大字＋陶土橙点缀"或"近黑底＋单一荧光强调色"这类与技术栈无关的默认套路上

### Requirement: 可读性与可访问性地板

产物 SHALL 满足：移动端不破版、宽屏与浏览器缩放时布局随视口生长（不得把内容宽度钉死在某个固定值上）、键盘焦点可见、尊重减少动效偏好、全部图片具备替代文本。

> 2026-09-19 修订：原条款要求"正文行长不超过约 80 字符"，开发者明确选择"文字也一起变宽、铺满屏幕"，故取消行长上限，改为要求**容器随视口生长**。行长可读性由字号同步放大来部分补偿（16→22px）。

#### Scenario: 窄屏不破版

- **WHEN** 以 375px 宽度视口打开产物
- **THEN** 无横向溢出，表格改为可横向滚动而非撑破版面

#### Scenario: 图片有替代文本

- **WHEN** 扫描产物内所有 `<img>`
- **THEN** 每一个均具备非空 `alt`

### Requirement: 记忆点克制集中

每页 SHALL 有一个集中呈现的开场记忆点，其余版面保持克制；非序列内容 MUST NOT 使用编号标记伪装成流程。

#### Scenario: 编号仅用于真实序列

- **WHEN** 某章节是历史沿革或冲煮步骤
- **THEN** 可采用顺序编号
- **AND** 若章节为并列知识（如种植地产区），则不使用 `01/02/03` 式顺序标记
