# 公开快照的排除清单（scripts/publish_public.py 读这里）
# 每行是一个**正则**，匹配 git ls-tree 给出的相对路径。
# 为什么要有这个文件而不是写在脚本里：排除什么是一个需要被人审的判断，
# 藏在代码里就没人会去读它。

# 第三方图片：图搜渠道抓来的品牌产品图、新闻图、社区图钉。

output/[^/]+/images/

# 采集器的内部账本：检索词与召回统计。线上包本来就不带它们（publish.SKIP 同源），
# 源码仓库里也不该有——它们记录的是"我们怎么找图"，不是产物。
output/[^/]+/images/manifest\.json
output/[^/]+/search-stats\.json

# 换名协议的现场文件：.pending 是闸门没过的那一份，.prev 是回滚凭据。
output/[^/]+/.*\.html\.(pending|prev)$
